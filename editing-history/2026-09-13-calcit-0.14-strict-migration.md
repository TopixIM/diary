# Calcit 0.14 strict migration / Calcit 0.14 严格模式迁移

## English

- Upgraded the project and direct Calcit dependencies to Calcit 0.14.15-compatible releases.
- Migrated the source snapshot from `compact.cirru` to the single canonical `calcit.cirru` file.
- Added closed structs and enums for persisted data, client stores, and server operations.
- Decoded persisted Cirru EDN and WebSocket operations into their declared nominal types.
- Replaced deprecated tag matching and legacy collection-method dispatch in reachable code.
- Kept browser/Respo state as the small intentional dynamic boundary; persisted and server-domain data remain closed.
- Updated CI to check both client and server entries and deploy pull-request previews only below `/pr/`.
- The server process and persisted production data were not started or modified during this migration.

## 中文

- 将项目及直接 Calcit 依赖升级到兼容 Calcit 0.14.15 的版本。
- 将代码快照从 `compact.cirru` 迁移到唯一的 `calcit.cirru`。
- 为持久化数据、客户端 Store 和服务端操作补充封闭的 Struct 与 Enum。
- 按声明的名义类型解析持久化 Cirru EDN 和 WebSocket 操作。
- 清理可达代码中的旧 `tag-match` 与遗留集合方法动态分派。
- 仅将浏览器/Respo 局部状态保留为有意的动态边界；持久化及服务端领域数据保持封闭。
- CI 同时检查客户端与服务端入口，并将 PR 预览严格部署到 `/pr/` 子路径。
- 本次迁移没有启动服务端进程，也没有读取或修改生产持久化数据。
